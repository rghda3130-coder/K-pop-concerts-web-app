# Submission Checklist

- [ ] Pull the latest team changes and resolve conflicts.
- [ ] Test from a clean installation where possible.
- [ ] Commit the exact submitted version.
- [ ] Copy the full commit hash using `git rev-parse HEAD`.
- [ ] Verify every submitted URL in a private/incognito window.
- [ ] Create the ZIP without `.git`, `node_modules`, `.env`, logs, or build output unless requested.
- [ ] Open the ZIP and confirm required source files are present.
- [ ] Confirm student names and IDs are correct.
- [ ] Submit through Moodle before the deadline.
- [ ] Do not modify the claimed submission version after submission without instructor approval.

# Milestone 1 Self-Check

## Application

- [ ] The React application runs after a clean `npm install`.
- [ ] Main/List, Login, Registration, and About routes work.
- [ ] Shared navigation works without full-page reloads.
- [ ] At least 10 structured mock records are loaded into state.
- [ ] Search/filter and sorting work together.
- [ ] Functional components, hooks, and props are used appropriately.
- [ ] The interface is usable at desktop and mobile widths.
- [ ] Empty results and relevant messages are understandable.

## Repository and Deployment

- [ ] All members have meaningful commits from their own accounts.
- [ ] No `.env`, credential, or `node_modules` content is committed.
- [ ] The Render front-end URL works in a private/incognito window.
- [ ] Refreshing a routed page does not produce a 404 error.

## Submission

- [ ] The ZIP matches the submitted commit and excludes `node_modules`.
- [ ] `submission-links.txt` contains names, IDs, repository URL, commit hash, and deployment URL.
- [ ] `README.md` contains setup instructions.
- [ ] `AI-USE.md` is included if significant AI assistance was used.

# Generative AI Use Guidance

AI tools may support learning and development, but they do not replace student responsibility.

## Appropriate Uses

- Explaining an error or unfamiliar concept.
- Suggesting debugging steps.
- Reviewing a small code section.
- Suggesting documentation wording.
- Generating an initial example that the student reviews, adapts, and tests.

## Requirements

- Understand all submitted work.
- Verify generated suggestions against project requirements.
- Test security-sensitive code such as authentication and authorization.
- Declare significant assistance in `AI-USE.md`.
- Identify affected files or features and explain how the output was reviewed or modified.

## Not Acceptable

- Submitting generated work that group members cannot explain or modify.
- Fabricating commits, tests, screenshots, contribution records, or deployment evidence.
- Entering passwords, connection strings, secret keys, or personal information into prompts.
- Using AI during an individual evaluation when instructed not to do so.

The instructor may ask any member to explain or change submitted code. The group's understanding and the application's behavior are more important than the tool used to produce an initial suggestion.
